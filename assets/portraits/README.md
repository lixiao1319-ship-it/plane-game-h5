# 武将头像素材

放置规则：文件名 = 武将 `id`（即武将中文名，见 `src/data/heroes.js`）+ 扩展名。

```
assets/portraits/曹操.jpg
assets/portraits/诸葛亮.png
```

- 支持 `.png` / `.jpg` / `.jpeg`，按此顺序尝试加载，命中即用。
- 图片会按"居中裁剪填满正方形"（object-fit: cover）方式渲染，不需要提前裁成方形，竖版全身图也可以直接用。
- 替换/新增素材**不需要改任何代码**：直接覆盖或新增对应文件名的图片即可，`src/core/ImageLoader.js` 会在下次渲染该武将时自动读取。
- 没有对应素材的武将会自动回退为色块+首字的占位卡片，不影响运行。

当前已提供 9 名武将头像（曹操、刘备、孙权、诸葛亮、关羽、张飞、吕布、司马懿、张辽），其余 92 名武将暂用占位卡片。
