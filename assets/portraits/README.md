# 武将头像素材

放置规则：文件名 = 武将的 `assetId`（ASCII 编号，如 `h001`）+ 扩展名。

```
assets/portraits/h001.jpg   # 曹操
assets/portraits/h004.png   # 诸葛亮
```

**不要用中文武将名做文件名。** WeChat 开发者工具本地开发环境下，`Image.src` 里的中文字符会被自动
URL 编码（如 `诸葛亮` → `%E8%AF%B8%E8%91%9B%E4%BA%AE`），但读文件时不会解码回去，导致本地永远
`ENOENT` 找不到文件（真机/线上环境未必有这个问题，但本地调试一定复现）。所以头像必须用
`assetId` 命名来彻底绕开这个坑。

- 每个武将的 `assetId` 见 `src/data/heroes.js` 里对应字段，或查 `docs/hero-asset-ids.md` 对照表
- 支持 `.png` / `.jpg` / `.jpeg`，按此顺序尝试加载，命中即用
- 图片按"居中裁剪填满正方形"（object-fit: cover）方式渲染，不需要提前裁成方形，竖版全身图可直接用
- 替换/新增素材**不需要改任何代码**：按 `assetId` 覆盖或新增对应文件名的图片即可，
  `src/core/ImageLoader.js` 会在下次渲染该武将时自动读取
- 没有对应素材的武将会自动回退为色块+首字的占位卡片，不影响运行

当前已提供 9 名武将头像（h001 曹操、h002 刘备、h003 孙权、h004 诸葛亮、h006 关羽、
h007 张飞、h008 吕布、h009 司马懿、h016 张辽），其余 92 名武将暂用占位卡片。
